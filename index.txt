JavaScript & TypeScript Fundamentals
Interviewers test core JS before anything else: closures, event loop/async (promises, async-await), prototypal inheritance, `this` binding, debouncing/throttling, and array/object methods. Since TypeScript is on your CV but not in any project yet, be ready to explain interfaces, generics, and union types at a basic level — expect at least one question probing whether you've really used it. Practice: rebuild 2-3 small utilities (debounce, deep clone, event emitter) from scratch without libraries.
2
React & Next.js Deep Dive
You'll get grilled on what you've actually shipped. Know React rendering behavior, hooks (useState/useEffect/useMemo/useCallback and why), key props, controlled vs uncontrolled inputs, and state management approaches (Context vs Redux/Zustand). For Next.js specifically: App Router vs Pages Router, SSR vs SSG vs ISR vs client rendering and when to use each, API routes, and how data fetching works. Be ready to explain exactly how you built the Artisan Collection e-commerce cart/checkout flow — that's your strongest proof point.
3
Backend, APIs & Auth
Cover REST API design (status codes, idempotency, pagination), the difference between REST and GraphQL (you've used both — know why you'd pick one), and middleware patterns in Express/FastAPI/Django/Laravel. Since your CV lists JWT and session-based auth, be ready to explain the actual auth flow you implemented in the Blog CMS and AI Summarization Tool projects step by step: token issuance, refresh, storage, and where it can go wrong (XSS/CSRF).
4
Databases: SQL & NoSQL
You've used MongoDB, PostgreSQL, MySQL, and Redis — interviewers will ask you to justify each choice. Know when to reach for a relational vs document database, basic normalization, indexing, and simple query optimization. For Redis, be ready to explain your caching strategy in the Blog CMS project (what you cached, cache invalidation approach). Practice writing a handful of SQL joins and MongoDB aggregation queries by hand — this trips up a lot of MERN-focused candidates.
5
DevOps, Docker & CI/CD
This is a real differentiator for you at junior level, so be ready to go deep rather than just name-drop it. Explain your Blog CMS Dockerfile/compose setup, what your GitHub Actions pipeline actually runs (tests, build, deploy stages), and basic Nginx reverse-proxy concepts. Also brush up on environment variables/secrets handling and the difference between an image and a container — these get asked as quick sanity checks.
6
Data Structures & Algorithms
Even full-stack roles in Pakistan increasingly include a DSA round. Focus on arrays/strings, hashmaps, two-pointers, basic recursion, and simple tree/graph traversal — LeetCode Easy to low-Medium is the right level for junior full-stack, not hard DP. Aim for 3-4 problems a day for two weeks on LeetCode or a Pakistani-friendly platform, and always practice explaining your approach out loud before coding, since that's what's actually being graded.
7
Project Deep-Dives & Behavioral Prep
For each of your 4 projects, prepare a 90-second walkthrough covering: the problem, your architecture decisions, one hard bug you hit and how you debugged it, and what you'd do differently now. This is what separates candidates who copy-pasted tutorials from ones who understand their own code. Also prepare 2-3 STAR-format stories (client communication from Bringoo Tech, working AI-agent debugging from DevelopersHub) since 'tell me about a time...' questions are near-universal even for technical roles.
